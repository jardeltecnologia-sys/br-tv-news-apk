# BR TV NEWS APK V7 — Ícone Premium

Esta versão mantém a base V6 que corrigiu:
- botão/prompt de instalação;
- carregamento mobile mais rápido;
- WebView com mídia e fullscreen;
- workflow que gera o projeto Android no GitHub Actions.

## Novo nesta V7

- Adicionado ícone premium do aplicativo com a arte BR TV NEWS enviada.
- Removido o ícone padrão/estranho do Android.
- Gerados ícones para mdpi, hdpi, xhdpi, xxhdpi e xxxhdpi.
- Adicionado roundIcon para launchers que usam ícone circular.
- Incluída prévia do ícone em docs/icone-brtv-news-premium-512.png.

## Observação

O workflow continua gerando o projeto Android no servidor do GitHub, igual à V6 que ficou verde.
A diferença é que ele copia os ícones do repositório para o projeto Android antes de compilar.
